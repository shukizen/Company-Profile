# Situs Marketing JCP

Situs PT Jogja Creative Production berbasis Next.js 16 App Router.

## Persiapan lokal

1. Pasang dependensi dengan `npm install`.
2. Salin `.env.example` menjadi `.env` dan atur `NEXT_PUBLIC_SITE_URL` ke alamat publik situs sebelum deployment.
3. Jalankan situs dengan `npm run dev`.

Pengunjung menghubungi tim JCP melalui tautan WhatsApp yang tersedia di halaman.
